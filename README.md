## 🚀 Project Overview
This repository is a learning lab for Azure AI Agents with Azure AI Foundry. It includes sample notebooks and a Python demo that help students learn how to:
- create and configure an Azure account
- enable an Azure subscription
- set up Azure AI Foundry resources
- run AI agent workflows using Microsoft AI frameworks

- Lesson: Azure account creation, Azure AI Foundry setup, and Azure subscription configuration

## 🌈 What is Microsoft Agent Framework?
Microsoft Agent Framework refers to the set of tools and SDKs that enable developers to build intelligent agent-based applications on Azure. These agents can:
- interact with users via natural language
- coordinate tasks across cloud services
- combine AI models, knowledge sources, and decision logic

### ✅ Key Features
- **Agent orchestration**: Manage multi-step workflows and agent collaboration
- **AI integration**: Use language models, knowledge bases, and plugins
- **Azure-native**: Connect securely to Azure services and resources

## 📘 Theory and Learning Goals
This session also covers the theory behind AI agents and their use in cloud applications.

### Theory Topics
- **What is an AI Agent?**
  - An AI agent is a software entity that perceives its environment, makes decisions, and acts autonomously to achieve goals.
- **Agent architecture**
  - Input processing, decision-making, action execution, and feedback loops
- **Why Azure AI Foundry?**
  - Azure AI Foundry provides tools and infrastructure for building, deploying, and managing AI agents in a scalable way.
- **Real-world use cases**
  - virtual assistants, automated workflows, customer support bots, and intelligent process automation

## 🧭 Getting Started
1. Create an Azure account at https://portal.azure.com
2. Activate an Azure subscription so you can provision resources
3. Create or access Azure AI Foundry / Azure AI services inside your subscription
4. Clone this repository to your local machine
5. Install Python dependencies from `requirements.txt`
6. Open the notebooks in `MAF Demo/` and run the examples

## 📦 Requirements
- Python 3.10 or newer
- Azure account and active Azure subscription
- Azure AI Foundry or Azure AI services enabled in your subscription
- `requirements.txt` installed before running the notebooks
